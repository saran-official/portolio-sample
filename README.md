# Saran Kumar — Portfolio

Intelligent, editorial-grade personal portfolio built with React, TanStack Start / React Router, Tailwind CSS, and Vite.

## Features

- **Editorial Design & Typography:** Custom typography and harmonious color palettes.
- **Interactive "Hover to Meet Me" Video Section:** Seamless video intro with responsive hover & click playback controls.
- **Projects Showcase:** Real landing page cover imagery and links for all featured projects (Futurole, Interactive Motel Work, Fix Campus Now, Smart Rental Management, and FilmoVault).
- **Services & Skills Matrix:** Deep-dive into software development, AI, IoT, digital marketing, and automation capabilities.
- **Responsive & Accessible:** Fully mobile-responsive, dark/light aesthetics, and keyboard accessible.

## Tech Stack

- **Framework:** TanStack Start / React Router
- **Build Tool:** Vite
- **Styling:** Tailwind CSS (v4)
- **Icons:** Lucide React
- **Deployment:** Vercel (Auto-detected via Nitro)

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:8080](http://localhost:8080) in your browser.

3. Build for production:
   ```bash
   npm run build
   ```

## Deploy to Vercel

This repository is ready to deploy directly on [Vercel](https://vercel.com):
1. Import this repository in Vercel.
2. Vercel will automatically detect the Vite / TanStack Start build.
3. Deploy!
